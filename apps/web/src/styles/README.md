# Venturi design-system integration

Version: 6.6.0. `venturi-tokens.css` is an unchanged copy of the attached canonical
`DESIGN-SYSTEM/IMPLEMENTATION/tokens.css`; edit upstream SOURCE/tokens.json and
regenerate before refreshing this file. `venturi-theme.css` maps the existing
application variable names to canonical semantic roles. Fonts and brand SVGs
are copied from the approved GENERAL-REFERENCE distribution.

The public portal uses the light operational register. The dark token adapter
is generated from the same canonical block to support existing `.dark` consumers.
Font license notices are retained with the self-hosted assets.
